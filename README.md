# Backend Study

백엔드에서 자주 만나는 개념을 주제별로 정리한 학습 노트다. 정의, 동작 방식, 실무에서 헷갈리는 지점, 면접에서 자주 나오는 질문을 한 문서에 모아 두었다.

## 목차

### 메시징

| 문서 | 다루는 내용 |
| --- | --- |
| [Kafka](./01-kafka.md) | 토픽, 파티션, 컨슈머 그룹, 전달 보장, 기존 메시지 큐와의 차이 |
| [MQTT 통신](./02-mqtt.md) | 발행/구독, QoS 0·1·2, 세션, Retain, Will, Kafka와의 차이 |

### 스프링 코어

| 문서 | 다루는 내용 |
| --- | --- |
| [AOP](./03-aop.md) | 관점, 포인트컷, 어드바이스, 프록시, 자기 호출 |
| [IoC](./04-ioc.md) | 제어의 역전, 컨테이너의 역할, DI와의 관계 |
| [Bean](./05-bean.md) | 등록 방법, 스코프, 생명주기 |
| [DI](./06-di.md) | 생성자·세터·필드 주입, 순환 참조 |

IoC가 원칙이고, DI는 그 원칙을 구현하는 방법이며, 컨테이너가 관리하는 객체가 Bean이다. AOP는 그 Bean을 프록시로 감싸 공통 관심사를 붙인다.

### 영속화와 트랜잭션

| 문서 | 다루는 내용 |
| --- | --- |
| [JPA](./07-jpa.md) | 영속성 컨텍스트, 더티 체킹, 지연 로딩, N+1 |
